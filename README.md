# LYNOX — Ultra Full-Stack Portfolio

بورتفوليو شخصي وهندسي فائق الأداء (HTML + CSS + JS) مصمم بأعلى معايير الويب العالمية، بدون Frameworks ثقيلة وبسرعة تحميل قياسية (100% Performance).
الدومين: `dev.lynox.org`

## 🌟 أبرز التحسينات والميزات المضافة
1. **مبدل الثيمات اللوني التفاعلي (Live Accent Themes):**
   - 5 ثيمات مميزة (Crimson Red, Cyber Cyan, Emerald Matrix, Neon Violet, Solar Amber).
   - حفظ تلقائي لاختيار الزائر في `localStorage`.
2. **محرك المؤثرات الصوتية (Web Audio API Synthesizer):**
   - أصوات رقمية وسينمائية خفيفة للمطورين (Micro-clicks, Terminal beeps, Success chimes) بدون ملفات صوتية خارجية.
   - زر كتم/تشغيل مع حفظ الحالة.
3. **شريط مؤشرات الثقة والأداء (Impact Metrics):**
   - عدادات رقمية متحركة (+25 مشروع، 99.9% جاهزية، <200ms سرعة استجابة، 100% رضا العملاء).
4. **حلول وخدمات العميل (Services Grid):**
   - بطاقات مصممة بعناية توضح القيمة المضافة لرواد الأعمال والشركات.
5. **معرض المشاريع المصنف (Filtered Project Showcase):**
   - استبدال البطاقات الوهمية بنماذج مشاريع احترافية متكاملة (SaaS, APIs, Bots, UI Kits) مع فلترة فورية حسب التصنيف.
6. **نموذج حجز مشروع تفاعلي وذكي (Project Inquiry Form):**
   - اختيار نوع المشروع بلمسة واحدة.
   - خيارات إرسال فوري عبر الإيميل أو مباشرة عبر واتساب بنص منسق وجاهز أو نسخ ملخص الطلب.
7. **قسم آراء العملاء والأسئلة الشائعة (Testimonials & Interactive FAQ):**
   - لتعزيز ثقة العميل وتسهيل اتخاذ قرار التعاقد.
8. **تيرمنال أوامر تفاعلي متطور (Supercharged Terminal):**
   - يدعم أوامر: `help`, `whoami`, `services`, `stats`, `projects`, `theme <name>`, `ping`, `matrix`, `quote`, `cat profile.ts`, `contact`.

## 🛠️ التعديل والتخصيص
- **تحديث البيانات:** عدّل `config.js` لتحديث الإيميل، الروابط، التقنيات، والخبرات.
- **تعديل الصفحات والنصوص:** عدّل في `tools/build.py` ثم شغّل:
  ```bash
  py tools/build.py
  # أو
  python3 tools/build.py
  ```
  ليتم إعادة توليد كافة الصفحات وملف `sitemap.xml` تلقائياً.
- **التصميم والألوان:** كل المتغيرات والأنماط في `style.css`.
