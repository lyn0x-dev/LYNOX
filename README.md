# LYNOX

بورتفوليو شخصي ثابت (HTML + CSS + JS) — من غير frameworks ولا build خطير. الدومين: lynox.org

## الشغل اليومي
- **المحتوى والروابط:** عدّل `config.js` فقط (الإيميل، GitHub، السيرة، الروابط، التقنيات، الخبرات). أي حاجة فاضية بتتخفي أو بتظهر "قريبًا".
- **تعديل النصوص / الـ header / الـ footer:** عدّل `tools/build.py` ثم شغّل:
  ```bash
  python3 tools/build.py
  ```
  بيولّد `index/projects/about/contact/404.html` و`sitemap.xml`. ارفع الملفات الناتجة كما هي (GitHub Pages).
- **الشكل:** كل الألوان في أول `style.css` (`:root`). الهوية: فضي + قرمزي مأخوذة من الصورة الشخصية.

## الملفات
`style.css` النظام البصري · `app.js` التفاعلات (intro، cursor، terminal تفاعلي، palette بـ Ctrl/⌘+K، glitch، curtain) · `og.png` صورة المشاركة · `favicon.svg` · `404.html`
